# Freight Rate Prediction — ML Assessment

Predicts freight shipping rates using a LightGBM model trained on Jan–Oct 2025 data.

## Setup

```bash
pip install -r requirements.txt
```

## Run everything with one command

```bash
python run.py
```

This will:
1. Load and clean the data (fill missing `weight` and `market_index` values)
2. Build features (distance, time, load, market signals, interactions)
3. Train the model using a **time-based split** (train Jan–Aug, validate Sep–Oct)
4. Print MAE / RMSE / MAPE for both baseline and LightGBM
5. Generate `validation_predictions.csv` (12,000 rows for Nov–Dec)
6. Fill in `data/december_chart_inputs.csv` and run `score.py` to generate the chart

## Output files

| File | Description |
|---|---|
| `validation_predictions.csv` | 12,000 predicted rates for the validation set |
| `data/december_chart_inputs.csv` | 31-day December forecast (Lexington → Fort Wayne) |
| `scorer_results/candidate_december.png` | December chart generated by score.py |
| `model.pkl` | Saved LightGBM model |

## Key design decisions

- **Time-based split**: Never use random K-fold. Validation set is in the future, so we train on Jan–Aug and validate on Sep–Oct to simulate real forward prediction.
- **Missing value strategy**: `weight` filled by equipment-type median; `market_index` filled by daily mean.
- **Model**: LightGBM with MAE objective (robust to outlier rates).
